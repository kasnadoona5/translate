# v20.6 Evidence And Controlled Trial

## Shipped Scope

The served-model accounting defect (R157/T57) is corrected: only a returned
`response_model` is a served identity. Missing identities are `unknown`;
requested routes are counted separately. Physical attempts, successful calls,
failures, tokens, active/lifetime scope and their denominators do not change.

Style and memory evidence now explicitly distinguish mechanical alignment,
stored model scores, existing policy admission and independent semantic review.
These report labels neither promote nor demote a memory entry. Research coverage,
proposal approval and semantic accuracy remain separate report fields.

Production prompts, stage order, all four memory layers, style floors/genres,
refiner veto, R109 attribution and the existing zero/one conditional extra-final
allowance remain unchanged. No new live reviewer or scheduled call is enabled.
The existing UI address, token authentication and unchecked term-review default
are unchanged. Year-digit changes and scholarly table reconstruction stay deferred.

The isolated trial tool can compare the existing and experimental critique and
refiner guidance with existing validators and job-configured routing. Its output
cannot activate production guidance. Local tests do not prove improved Persian
or certify production readiness.

## Safe VPS Update

Wait for jobs and worker leases to be inactive. Do not start/resume jobs during
deployment. Run this block; Ctrl+C ends only the log viewer, not the nohup process.

```bash
(
set -Eeuo pipefail

tail --retry -F "$LOG"
)
```

Require `Deployment v20.6 completed. Running 9router was unchanged.` in the log.
The script checks jobs/leases before backup and replacement; makes a consistent
SQLite online backup including WAL contents; verifies integrity, gzip, isolated
restore and hash; refuses snapshot overwrite; and preserves local config/glossary.
It verifies the tagged Git revision, Docker image revision, runtime/capabilities
and health. Code-only deployment retains the existing dependency contract.

Space cleanup removes only verified unused Tarjomeh resources, never router
containers/images/data/backups, unrelated containers, or global Docker resources.
9router ID, image, start time and mounts must remain identical. The current
Tarjomeh rollback image is now retained after health verification. If the backup
reserve or 350 MB build reserve is unavailable, deployment stops. Do not bypass
the guard or remove running images. This procedure is locally tested, not a claim
that deployment has already succeeded on your VPS.

## Full Audit After A Job

Use matched source/settings and the same chapter checkpoint for comparisons.
Mandatory terminology still requires approval of the meaning and every intended
occurrence. Keep automatic enforcement OFF. Check the previously blocked job
separately; a fresh successful checkpoint is not proof of resumed-job recovery.

```bash
(
cd /opt/translate || exit 1
JOB=YOUR_ACTUAL_JOB_ID
REPORT_RC=0
bash scripts/audit_tarjomeh_v206_reports.sh "$JOB" || REPORT_RC=$?
COMPANION_RC=0
bash scripts/audit_tarjomeh_v206_companion.sh "$JOB" || COMPANION_RC=$?
printf 'Reports exit=%s Companion exit=%s\n' "$REPORT_RC" "$COMPANION_RC"
[ "$REPORT_RC" -eq 0 ] && [ "$COMPANION_RC" -eq 0 ]
)
```

Both audits run even if one fails. Hard failures return nonzero, never PASS.
Reports include active/lifetime call/failure accounting, retries/helper calls,
served/requested models, stages, research, terminology, four memories, style,
extra-final work, canonical identities and delivered DOCX proof. `REVIEW` is
not semantic certification. `model_identity_accounting` and
`v206_quality_safeguards` expose the new report-only evidence.

Send the same job's DOCX, QA TXT, memory JSON/TXT, companion JSON/TXT,
server companion TXT and the complete deployment log. Preserve older files
for matched comparisons. A short checkpoint does not test the remaining book.

## Isolated Quality Trial

This is a separately authorized paid experiment, not part of translation.
`--execute` permits calls; without it, no credentials are loaded and no model
is called. The database is read-only. Output files are private and exclusive;
use a new directory for each phase. Partial calls are saved immediately. Do not
restart an interrupted paid run as though it were free or automatically resumable.

Inputs are 16 exact saved v20.5 chunks and two human-confirmed property controls:
the correctly scoped v20.4 institutionalism passage, and the source-faithful
v10.37 state-power attachment. Control JSON is a two-element list, each with
`id`, `kind: "known_good"`, `property`, exact `source` and `target`. Book-derived
controls belong in local trial fixtures, not production prompts or self-checks.

Optional context JSON is keyed by case ID (`chunk:0` through `chunk:15` and the
control IDs). Each entry may contain `terminology`, `review_context`, `provenance`
and `existing_reports`. Every existing report must bind `source_sha256` and
`target_sha256`. Missing original context is explicitly reconstructed, never
claimed to match history. Claim `exact_saved_and_hash_verified` only after
independently checking the original context; compare every arm on the same text,
terminology and bounded context. Missing baseline reports prevent catch credit.
No saved score or template hash alone proves original context availability.

Prepare/upload the reviewed control/context files, then dry-run:

```bash
cd /opt/translate || exit 1
JOB=68fac94929f1
docker exec -i translate_tarjomeh_1 env PYTHONIOENCODING=utf-8 python -u - "$JOB" \
  --controls /app/jobs/uploads/v206-controls.local.json \
  --context /app/jobs/uploads/v206-context.local.json \
  --out "/app/jobs/uploads/${JOB}_v206_dry_run" \
  < scripts/replay_tarjomeh_v206_quality.py
```

For an approved paid run, add `--execute` and use a different output directory.
The tool uses the saved job settings and locally configured credentials with
the production critic-role selector, including 9router endpoints. It does not
substitute a new provider, token cap, model or recovery policy. Its OpenRouter
provider name can describe the existing OpenAI-compatible 9router route.

The three arms are two ordinary critiques and one proposed critique: 54 logical
calls, plus the existing bounded transport/JSON helpers. All successful served
model identities must agree per case; a failed attempt without returned model
is not a model mismatch. An inconclusive case can be explicitly rerun once with
`--rerun-case CASE_ID --previous-results PATH`, identical frozen inputs/settings/
templates and a fresh output directory. The extra three logical calls are
reported separately; mismatches remaining after that cannot earn evidence credit.

`results.json` includes the adjudication table, both ordinary baselines, all
provided same-text reports, exact-quote checks, physical cost and property controls.
Unsupported/ignored findings are retained, not hidden from precision. Human review
must compare against ordinary critique, readability, language and structure checks,
including all deterministic detectors on the same candidate. Name and assess the
actual positive cases P45, P84, P92, P180 and P184; P90/P181 retain ambiguous-proof
REVIEW rather than earning an unsafe deterministic repair. No synthetic catch
earns credit and no control claims that its entire paragraph is flawless.

Go/no-go requires at least two distinct real catches missed by both ordinary
passes and every existing same-text check; precision at least 80%, with false,
uncertain, pending and unsupported findings in the denominator; property controls
preserved; compatible successful served models; source-based human adjudication;
and approval of the evidence/cost table. A zero-finding trial fails. There is no
LLM judge deciding the winner.

The subsequent `--refine-decisions PATH --execute` phase needs human-approved,
hash-bound issue lists for at most 18 cases. Each item contains `id`,
`human_approved: true`, `source_sha256`, `target_sha256`, `context_sha256` and
one to eight `issue_details` with unique IDs and exact source/current target quotes.
Both refiner arms receive identical issues, including false-advice veto controls.
There are at most 36 refiner calls and 36 ordinary changed-candidate critiques:
126 logical calls across phases before retries/helpers or explicitly requested
model-mismatch reruns. Unchanged preserved candidates require no re-critique.

The tool deliberately reports `admission_and_export_trial: NOT_RUN`: a reviewer
or refiner comparison is NOT a full pipeline replay. Before any production prompt
adoption, run candidates through all actual admission/memory/export gates in
disposable isolated state, prove source/target/local diffs, canonical hashes,
refiner veto, R109, source obligations and DOCX identity, and inspect the exact
Persian against the source. Record newly triggered final-repair passes and their
refinement/re-critique costs, not just nominal allowances. This remaining gate
must not be replaced by a judge score or a checkbox in JSON. The optional
guidance remains OFF while live evidence/adjudication is unavailable or fails.
