# v20.8.11: Chunk-Local Final Entity Evidence

The final automatic-name safeguard now compares unresolved quality findings
with the entity's chunk-local paragraph, not its document-wide paragraph.
Unknown, non-integer and out-of-range issue scope defers the automatic mapping.
Document-wide provenance indices retain their existing meaning; reports add
explicit local/global indices. Existing quality-record formats are unchanged.

Deferral preserves the stored observation as history and excludes it from
automatic reuse. It does not rewrite translation, approve an unresolved chunk,
or create an export failure. Curated/user/accepted mappings remain protected.

The new `final_entity_local_issue_scope` capability has a pure behavior probe
using the actual quality-record producer and nonzero document offsets. Deployment
and both collectors require it alongside previous safeguards. Regression tests
exercise same/unrelated paragraphs, invalid scope, restore and all DOCX layouts.

Production prompts, models, stage order, thresholds, budgets, all four memory
layers, research/style policies and reviewed-term scopes are unchanged. This
release adds no production LLM call. Semantic summary drift and translation
editing remain separate quality concerns, not certified by runtime probes.

Use the versioned deployment script, which retains consistent SQLite backup,
isolated restore verification, exact revision checks, rollback and guarded
Tarjomeh-only cleanup. It neither prunes shared Docker resources nor changes
9router. Low space stops deployment safely; no script can guarantee enough
space exists on every VPS.

The versioned combined audit runs both collectors and preserves nonzero failure
status. Existing published checkpoints do not need Resume just to run audits.
Tests and source/output replay establish local verification, not universal
translation accuracy or a live exercise of every safeguard.
